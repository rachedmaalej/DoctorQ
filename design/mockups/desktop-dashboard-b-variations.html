BléSaf — Left Panel Design Variations

Same data and actions, 3 distinct information architectures for the 390px control panel. All 3 share an identical minimal topbar.

1 — Stratified Workflow Order Top-to-bottom hierarchy mirrors the doctor's cognitive sequence: queue status → current patient → day stats → next action → secondary tools → admin controls. Each group is visually delimited. The eye travels down the panel in natural workflow order. Presence, language, and settings are tucked in a clean footer so they don't compete with clinical content.

2 — Action Hub CTA-First The primary action — "Appeler Suivant" — is anchored at the very top, always reachable without scrolling. The current consultation compresses into a dark horizontal bar immediately below. Stats, tools, and controls follow. Presence, language, settings in a clean footer. Optimised for fast-paced sessions where the call-next action repeats dozens of times per hour.
