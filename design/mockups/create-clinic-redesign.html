A — Stepper Wizard

Breaks the 7 fields into 4 focused steps with a progress indicator. Reduces cognitive load and guides the admin through each section.
Pros
Low cognitive load per step
Clear progress tracking
Review before submit
Cons
More clicks to complete
Can feel slow for power users
Needs back-navigation

+ New Clinic

B — Sectioned Card

All fields visible in one view, organized into 3 color-coded sections. Quick for experienced users while maintaining visual hierarchy.
Pros
Everything visible at once
Fast for repeat use
Clear field grouping
Cons
More visual density
Longer scroll on mobile
Less guidance for new users

C — Side Panel Drawer

A right-side drawer that keeps the main page visible. Feels native to admin dashboards and doesn't block the workspace.

Native admin feel
Compact single column
Cons
