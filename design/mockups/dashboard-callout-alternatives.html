Tableau de bord — Callout Animations

4 approches pour animer les annotations du mockup dashboard. Chaque onglet a son propre style d'entrée.

A — Sequential Spotlight

« Une histoire à la fois »

Les annotations apparaissent une par une : point pulsant, ligne dessinée, puis tooltip. Le regard est guidé dans un ordre précis.

Comment ça marche
  • Point 1 apparaît (200ms)
  • Ligne se dessine du point au tooltip (500ms)
  • Tooltip glisse et apparaît (300ms)
  • Répéter pour 2, 3, 4

B — Carousel Focus

« Un projecteur qui tourne »

Un seul tooltip visible à la fois. Le point actif brille plus fort, les autres sont atténués. Boucle automatique toutes les 3 secondes, cliquable.

Comment ça marche
  • Un seul tooltip + point actifs
  • Boucle auto toutes les 3s
  • Cliquer un point ou un indicateur pour sauter
  • Pas de lignes — lien visuel par couleur

C — Hover Reveal

« Explorez à votre rythme »

Les points sont visibles dès le scroll. Survolez (ou tapez) un point pour révéler son tooltip. Un seul visible à la fois. Auto-cycle après 3s d'inactivité.

Comment ça marche
  • Tous les points visibles immédiatement
  • Hover/tap révèle le tooltip associé
  • Lueur directionnelle entre point et tooltip
  • Auto-cycle si aucune interaction

D — All-at-Once Stagger

« L'image complète, en douceur »

Tout apparaît en rafale rapide (~1.5s). Le téléphone glisse vers le haut, les points éclatent, puis les tooltips arrivent en cascade. Des petits traits pointillés CSS remplacent les lignes SVG.

Comment ça marche
  • Téléphone monte (300ms)
  • 4 points apparaissent ensemble (200ms)
  • Tooltips en cascade (150ms chacun)
  • Traits CSS pointillés, pas de SVG
