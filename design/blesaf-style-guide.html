Règles d'usage

DO — À faire
  • ✓Utiliser les tokens CSS (--bs-*, --ob-*) plutôt que les valeurs hex directes dans les composants
  • ✓DM Sans partout dans le dashboard · Sora exclusivement dans l'onboarding
  • ✓Touch targets ≥ 44px sur mobile
  • ✓Utiliser material-symbols-rounded pour toutes les icônes système
  • ✓Bottom sheets pour les sélections sur mobile (≥ 5 options)
  • ✓Fond crème #F6F5F0 comme base du dashboard réceptionniste
DON'T — À éviter
  • ✗Mélanger les tokens --ob-* et --bs-* dans un même composant
  • ✗Utiliser <select> natif dans les flows d'onboarding ou de paramètres
  • ✗Icônes Outlined ou Sharp dans le dashboard receptionniste
  • ✗Scroll horizontal ou contenu tronqué sans indication visuelle
  • ✗Animations > 300ms pour les interactions utilisateur directes
  • ✗Utiliser la police Sora dans le dashboard (hors onboarding)
